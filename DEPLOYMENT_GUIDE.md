 ├── apiKey: string\n│       ├── email: string\n│       ├── savedAt: timestamp\n│       └── isActive: boolean\n│\n└── exam_results/ (Collection)\n    └── {resultId}/ (Document - Auto-generated)\n        ├── userId: string\n        ├── displayName: string\n        ├── topicName: string\n        ├── score: number\n        ├── correct: number\n        ├── wrong: number\n        ├── date: timestamp\n        └── attempt: number\n```\n\n### Firestore Security Rules\n\n```javascript\nrules_version = '2';\nservice cloud.firestore {\n  match /databases/{database}/documents {\n    // User API Keys - User specific\n    match /user_api_keys/{uid} {\n      allow read, write: if request.auth.uid == uid;\n    }\n    \n    // Exam Results - Logged-in users can read/write\n    match /exam_results/{document=**} {\n      allow read, write: if request.auth != null;\n    }\n  }\n}\n```\n\n---\n\n## 🎯 Key Features\n\n### ✨ API Management\n- Secure Firebase storage of Gemini API Check Firebase authentication (user must be logged in)\n2. Verify Firestore security rules\n3. Check browser console for errors\n4. Clear browser cache and try again\n\n### Problem: Questions Not Showing\n**Solution:**\n1. Ensure `question-editor.js` is added to file\n2. Check if `window.questions` array is populated\n3. Verify no JavaScript errors in console\n4. Hard refresh browser (Ctrl+Shift+R)\n\n### Problem: Gemini API Not Working\n**Solution:**\n1. Test API key in API Settings modal\n2. Ensure API quota not exceeded\n3. Check API key format (should be long string)\n4. Verify internet connection\n5. Check for typos in prompt\n\n### Problem: Firebase Connection Issues\n**Solution:**\n1. Check Firebase console project status\n2. Verify Firestore is enabled\n3. Check security rules in Firestore\n4. Ensure user is authenticated\n5.
